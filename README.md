# Devis & Factures

Outil de devis et de factures pour PME, artisans et commerces.
Fonctionne sans Internet : les donnees restent dans le navigateur de l'appareil.

## Utilisation

Ouvrir `index.html` dans Chrome, puis « Ajouter a l'ecran d'accueil » sur telephone.

## Mentions

Le numero de facture normalisee electronique (FNE) est delivre par la plateforme de la DGI.
Cet outil prepare le document ; il ne certifie pas les factures.
